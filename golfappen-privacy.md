# Golfappen: Privacy Policy

Golfappen is a tool developed by 7rip7ych and compiled to an Android app using Median.co. The tool is accessible on [7rip7ych.com/golfappen.html](https://7rip7ych.com/golfappen.html) and the source code is openly available on [Github](https://github.com/7rip7ych/website/tree/Golfappen).


## Data collection

As the app was developed primarily for personal use, I, as the developer, have no interest in collecting any user data. Currently, the app does not collect or share any data and any data that is saved is stored locally on the device. This is likely to change in the future, in which case data will strictly be collected for the app's functionality. This would be in the form of impersonal crash logs, externally stored history, public leaderboard scores and such.


## Permissions

The app should currently not require any permissions. Any future permissions will not be required for the app to function but simply optional to use certain features.

## Contact
If you find any security vulnerability with the app, or have any questions regarding this privacy policy, feel free to send me an email or post a discussion on GitHub, and I will try my best to respond in a timely manner.
